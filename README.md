# React Day 20 – Form Validation 🚦

A small React app that validates a simple form in real time using `useState`.  
The goal of this exercise is to learn **controlled inputs**, **live validation**, and **error messages**.

---

## 🚀 Features
- Live email validation  
- Live password validation  
- Error messages shown immediately  
- Clean and simple UI  

---

## 🛠️ Tech Stack
- React
- JavaScript
- CSS
- createRoot API
